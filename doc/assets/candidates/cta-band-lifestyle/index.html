Two things to weigh

Faces imply endorsement. The Pexels licence allows commercial use but not using an identifiable person in a way that suggests they endorse a product — which is exactly what a stock face beside a health claim can read as. Frames 07–10 are hands only and carry none of that risk.

Blank screens are an opportunity. 08 and 09 hold a phone with an empty screen — the app UI can be composited in, so the band shows the real product instead of a generic phone. That is the version that actually sells a download.
